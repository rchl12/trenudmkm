Pertanyaan umum

Dari mana data tren berasal?

Contoh data di dashboard ini mengacu pada format Google Trends. Untuk data asli, sambungkan ke sumber data Anda.

Apa arti skor 0-100?

Skor menunjukkan tingkat minat pencarian relatif. 100 berarti puncak minat, 0 berarti sangat rendah.

Seberapa sering data diperbarui?

Tanggal pembaruan tampil di bagian atas Dashboard. Pada versi statis, data diubah manual di file HTML.

Bagaimana cara menambah keyword?

Buka Riset Tren, lalu tambahkan baris baru pada tabel keyword di file riset-tren.html.

Bisakah saya mengekspor laporan?

Gunakan Ctrl+P di browser, lalu pilih Simpan sebagai PDF.
